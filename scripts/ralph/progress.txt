## Codebase Patterns
- Frontend: Next.js App Router, all pages are "use client" components
- Auth state: stored in both localStorage and cookies (auth_token, user_role, user_id, username)
- Middleware at `frontend/middleware.ts` handles route protection via cookie checks (no JWT verification at edge)
- Roles: student, teacher, admin — mapped to route prefixes /student, /teacher, /admin
- Each role portal has its own sidebar/topbar; student has a layout.tsx wrapper, teacher/admin handle layout in each page.tsx
- Icon component at `frontend/components/Icon.tsx` — must check available icon names before use (no "warning" icon, use "alert-circle")
- Backend auth: JWT via python-jose, role stored in User.role field
- Backend error standardization: ALL routers use `errors.py` functions (`require_role`, `raise_resource_forbidden`, `raise_unauthorized`, `raise_invalid_credentials`) for auth/role/ownership errors — no inline HTTPException for 401/403
- Error response format: structured dict `{"message": "...", "error_code": "AUTH_REQUIRED|INVALID_CREDENTIALS|INSUFFICIENT_ROLE|RESOURCE_FORBIDDEN"}`
- Backend dev bypass: token "dev-bypass" accepted in non-production env, maps to user_id=1
- Backend tests: some pre-existing failures in integration tests (auth issues) and unit tests (test_agents.py)
- Student resource authorization: `ensure_student_owns_resource(user, db, student_id)` in deps.py checks Student.user_id matches current user for student role; admin/teacher bypass
- NOT NULL constraints: TeacherComment.report_id, Resume.student_id — always provide valid values in test fixtures
- CORS safety: global exception handler in main.py explicitly adds CORS headers to 500 responses as a belt-and-suspenders approach; endpoints that call LLM or complex DB queries must wrap all failure-prone operations in try/except
- Trailing slash rule: api_router uses `redirect_slashes=False`; all frontend calls to routes defined as `@router.get("/")` MUST include trailing slash (e.g., `/files/` not `/files`). Sub-paths like `/files/upload` are unaffected.
